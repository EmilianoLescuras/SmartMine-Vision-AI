# SPEC-003 — Notebook Workflow: Conflict-Free Collaboration

## Status
`IMPLEMENTED`

## Problem

Jupyter notebooks (`.ipynb`) are JSON files that embed execution metadata
alongside code:

- `execution_count` — per-cell counter (1, 2, 3…) that increments each run
- `outputs` — stdout, stderr, images, and rich display objects
- `id` — cell identifiers (stable within a generation, but outputs diverge)

When two collaborators run the same notebook independently and then open a PR
against `develop`, git sees those fields as **conflicting edits** even though
the underlying code is identical. The result is a three-way merge conflict on
every notebook, which must be resolved manually.

## Solution

Install **`nbstripout`** as a persistent git filter declared in `.gitattributes`.

`nbstripout` is a lightweight Python tool that strips `outputs` and resets
`execution_count` to `null` **at staging time** (i.e., whenever a file is
added to the git index). The stripping is transparent:

- Locally, the notebook still runs and shows outputs as expected.
- When staged (`git add`), git pipes the file through `nbstripout` before
  computing the diff and writing to the index.
- What is committed is always a clean, output-free notebook.
- `git diff` and `git log` show diffs of code only — not noisy output blobs.

Because all collaborators commit clean notebooks, **execution metadata never
reaches the remote** and merge conflicts on that metadata are structurally
impossible.

## Acceptance Criteria

1. `nbstripout` is declared in `requirements.txt` and `environment.yml`.
2. `.gitattributes` maps `*.ipynb` to the `nbstripout` filter.
3. A `Makefile` target `make dev-setup` installs the filter locally.
4. Running `make dev-setup` followed by staging an executed notebook produces
   a diff that contains only code changes (no `execution_count` or `outputs`).
5. `README.md` documents the one-time setup step for new collaborators.

## Implementation Details

### `.gitattributes`

```
*.ipynb filter=nbstripout
*.ipynb diff=ipynb
```

The `filter=nbstripout` line is sufficient for conflict prevention. The
`diff=ipynb` is optional cosmetic (makes `git diff` show notebook diffs
via nbstripout's pretty-printer).

### `Makefile` target

```makefile
dev-setup:
    pip install nbstripout
    nbstripout --install
    nbstripout --install --attributes .gitattributes
    @echo "nbstripout filter installed. Notebooks committed clean."
```

### Scope

- Applies to **all** `*.ipynb` files in the repository.
- Does **not** affect local execution: outputs are preserved in memory and
  visible while the kernel is running.
- Consistent with the existing convention that notebooks are generated by
  `scripts/generate_notebooks.py` and stored clean.
